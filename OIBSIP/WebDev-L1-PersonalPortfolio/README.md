# WebDev L1 · Task 2 — Personal Portfolio

**Track:** Web Development & Designing (Level 1)
**Subject:** Maya Chen, a fictional frontend developer (replace with your own name/photo/links before submitting)

## Objective
A personal portfolio site — your digital résumé — built with HTML5, CSS3, and a small amount of vanilla JavaScript.

## Tech stack
- HTML5
- CSS3 (Grid + Flexbox)
- Vanilla JavaScript (active nav-link highlight on scroll)

## Features implemented
- [x] Profile/hero section with name, role title, and avatar placeholder
- [x] About/bio copy (2–3 sentences)
- [x] Skills section as a 3-column grid (Languages / Frameworks / Tools)
- [x] Projects section with 2 project cards (title, description, GitHub link placeholder)
- [x] Contact/footer section with email and social links
- [x] Smooth scroll navigation (`scroll-behavior: smooth` + JS active-link tracking)
- [x] Consistent branding: navy background, mint accent, Space Grotesk + Inter
- [x] Fully responsive down to mobile widths

## Before you submit — personalize it
1. Replace "Maya Chen" with your name throughout `index.html`.
2. Swap the avatar initials/gradient for your own photo if you'd like.
3. Replace the two project cards with your real projects and real GitHub links.
4. Update the email and social links in the footer.

## How to run
Open `index.html` directly in a browser — no build step required.
