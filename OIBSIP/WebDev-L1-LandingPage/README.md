# WebDev L1 · Task 1 — Landing Page

**Track:** Web Development & Designing (Level 1)
**Subject:** Ember & Oak, a fictional small-batch coffee roastery

## Objective
A static, responsive landing page built with pure HTML5 and CSS3 (no JavaScript), establishing foundational layout skills.

## Tech stack
- HTML5
- CSS3 (Flexbox + Grid, no framework)
- Google Fonts: Fraunces (display) and Inter (body) — swap the `<link>` in `index.html` for the live Google Fonts embed if you want the exact faces to load; the CSS already falls back gracefully to system serif/sans-serif.

## Features implemented
- [x] Sticky nav bar with 4 links (Beans, Process, Visit, Order beans CTA)
- [x] Hero section: eyebrow, headline, subheadline, CTA button
- [x] 3 distinct content sections (Beans grid, Process steps, Visit)
- [x] Footer with address and placeholder contact/social links
- [x] Consistent palette: cream paper, espresso brown, amber accent, teal highlight
- [x] Responsive layout via CSS Grid/Flexbox — collapses to single column under 760px
- [x] Deliberate spacing/box-sizing throughout, no overlapping elements
- [x] Two type sizes/families: Fraunces for headings, Inter for body

## How to run
Open `index.html` directly in a browser — no build step or server required.
